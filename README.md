# Ranch des Quatre Vents

Jeu de chevaux en 3D dans le navigateur. Ouvrir la page une fois avec internet, puis
« Ajouter à l'écran d'accueil » : il se lance ensuite sans connexion.

Page : https://ntravarddaddy-crypto.github.io/ranch-quatre-vents/

Ce dépôt est la version publiée (générée) ; le code source vit ailleurs.
